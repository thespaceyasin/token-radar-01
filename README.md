A token launch radar over a frozen DefiLlama snapshot (758 protocols, 14 Nov 2026): it ranks the 198 genuine pre-token launch candidates by an implied value — TVL × 0.20, stretched by saturating growth, age and chain-diversity factors — and gives each one a concrete farm plan with costs and durations, on a sortable, filterable dashboard. Exchanges, bridges and wrapped products are set aside, and protocols whose token already trades are shown apart at their market values.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../../token-radar-01-kit/input/snapshot.json
```
